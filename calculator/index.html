Technical details

CID with calculated CRC:

The password is 16 binary bytes shown as 32 hexadecimal characters. The ESP32 tool converts the characters to the correct bytes.

What is CID, and where do I find it?

CID is the identity stored in the SD card itself, separate from the USB reader's serial number. An ordinary USB reader can copy maps without necessarily supporting CID reads or card locking.

With the ESP32 setup below, click Read CID. If you already have CID from another tool, paste it above.

A compatible native SD slot may let you do the card setup without ESP32, but it also needs suitable CMD42 software. I haven't tested that route myself.
